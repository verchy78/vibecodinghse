# Голосовой ввод в локальный чат Qwen

## Что добавлено

- Кнопка **🎙** возле строки ввода: первое нажатие начинает запись, повторное завершает запись и запускает распознавание.
- Расшифровка выполняется **локально** моделью `Qwen/Qwen3-ASR-0.6B` (поддерживает русский и другие языки).
- Распознанные слова появляются в строке ввода, **не отправляются автоматически**. Можно исправить текст, затем нажать **↑** или Enter.
- Распознавание и захват аудио работают в потоках; интерфейс остаётся отзывчивым. Максимальная длительность записи — 120 секунд.
- Основную Qwen3.5-4B (или другую модель чата) и функции `ai_client.py` **не меняли**.

> Qwen3.5-4B не является специальной моделью распознавания речи. Для микрофона используется Qwen3-ASR-0.6B. Модель загружается при первой расшифровке, затем остаётся в памяти для последующих записей.

## Установка

1. Поместите `app.py` и `voice_input.py` рядом с **вашим существующим** `ai_client.py` и остальными файлами приложения.
2. В том же Python-окружении, где запускается ваше приложение, установите пакеты:

   ```bash
   python -m pip install -U sounddevice qwen-asr
   ```

   Если PySide6 ещё не установлен, установите и его: `python -m pip install PySide6`.

3. Запустите приложение:

   ```bash
   python app.py
   ```

4. Разрешите операционной системе доступ к микрофону для приложения/интерпретатора Python. При **первой** расшифровке потребуется интернет для скачивания весов Qwen3-ASR. Для последующих распознаваний интернет не нужен, если модель уже скачана в локальный кэш.

## Дополнительные настройки

По умолчанию определяется язык автоматически, а модель использует CUDA при наличии доступной CUDA-видеокарты, иначе CPU. Необязательные переменные окружения:

- `QWEN_ASR_DEVICE=cpu` — выполнять распознавание только на CPU, если видеопамять занята моделью чата.
- `QWEN_ASR_LANGUAGE=Russian` — принудительно использовать русский; `auto` — автоматическое определение (по умолчанию).
- `QWEN_ASR_MODEL=путь_к_модели` — использовать заранее скачанные веса модели вместо скачивания.

Чтобы скачать веса отдельно, следуйте [официальной инструкции Qwen3-ASR](https://github.com/QwenLM/Qwen3-ASR#released-models-description-and-download).
